# 广州 → 中山情侣两天一夜｜静态旅行网页

双击打开 `index.html` 即可使用；不需要 Node、服务器、地图 API Key 或网络权限才能查看主内容。点击页面中的“高德导航 / 百度地图 / Apple 地图 / 原始来源”时需要联网。

## 文件

- `index.html`：网页结构与完整攻略内容。
- `style.css`：移动优先的视觉样式及打印样式。
- `data.js`：路线、时间轴、拍照教学、酒店、餐饮和来源数据。
- `script.js`：可展开时间轴、筛选、无 Key 路线示意图、点位导航和“无脑模式”。

## 使用说明

1. 用 Chrome、Edge 或 Safari 打开 `index.html`。
2. 时间轴点击卡片查看每一段 A→B 的交通、时间、费用和导航链接。
3. 点“无脑模式：下一站”可逐步高亮行程。
4. 点击地图标记后，选择高德、百度或 Apple 地图做实时导航。
5. 出发前 24—48 小时在 12306、酒店预订页、高德地图和天气预报中核验动态项目。

## 信息边界

- 网站明确区分“位置/特色的公开来源”和“会变化的车次、价格、评分、营业状态”。后者不伪装成固定准确值。
- 社交平台照片没有被下载或嵌入。灵感区只保留公开可访问链接，并写明是否为原帖。拍照动作与手机参数是原创教学。
- 路线图为无 API Key 的关系示意，非比例尺、非实时路况地图；导航请以外部地图应用为准。

## 资料核验

页面“资料来源与复核入口”保留每一条的标题、URL、用途与核验日期（2026-08-08）。优先来源包括中山市政府、12306、地图服务和酒店/餐饮公开预订页。
